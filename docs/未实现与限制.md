## 1. 受环境限制的功能

### 1.1 安装后必须重启 DSH 才能激活

- **现状**：DSH 在进程启动时建立模块解析表；在运行中的进程里新增或替换 bundle 时，宿主要求进程重启
  （`ResolutionRouter.replace()`：`replacing <name> requires a process restart`）。安装/升级版本号后，
  该 bundle 会在 `Config listConfigs` 中显示为 `inactive`，`math_*` 工具不会注册。
- **影响**：安装或升级后不能立即在同一个 DSH 进程里使用，必须重启 DSH。
- **已验证**：用宿主自身的 loader（`loadProfileDirectory` + `createRuntimeResolution` +
  `readProfilePatches` + `boot`）在隔离 profile 中启动，插件**可以**正常导入、注册 14 个工具并真机执行
  （证据脚本 `_verify/scratch_boot_full.mjs`，输出 `_verify/scratch_boot_full_out.txt`）。
  即：限制来自「活进程状态陈旧」，不是插件本身加载失败。
- **替代做法**：安装后重启 DSH；重启前可用上述隔离启动脚本自证插件可用。

### 1.2 pnpm 对同路径 `file:` tarball 的复用

- **现状**：profile 用 `dsh-math: file:E:/dsh-math/_dist/dsh-math-1.0.2.tgz` 这类依赖时，
  **内容变了但文件名/版本号没变**，pnpm 会按 lockfile 复用已解包的旧副本，不重新导入。
- **影响**：改了插件内容后直接重装，可能仍是旧代码。
- **替代做法**：每次改动后提升 `plugin/package.json` 的 `version` 并重新打包（得到新文件名）再安装；
  若旧包已删除，记得先同步改 profile 的 `package.json` 依赖路径，否则 pnpm 会报 `[ENOENT] … no such file`。

### 1.3 图片输入依赖 DSH 原生多模态

- **现状**：插件本身**不做任何图像解析**（没有 OCR、没有外部视觉服务）。图片题依赖 DSH 原生多模态
  （`read_image` / `modlens_read_image`）把题目转成文本，再交给 `math_*` 工具。
- **影响**：若当前环境的多模态引擎不可用，图片输入就无法完成，需要用户把题目转成文本。
- **如实说明**：本次交付**未做端到端图片测试**（测试报告中标为「未验证」），只保证「图片 → 数学工具」
  这条链路在文本层面成立：识别结果由用户确认后再计算。
- **替代做法**：直接把题干文字粘贴到对话里。

## 2. 考研数学一考纲中尚未实现的内容

以下为**明确未覆盖**的考点。工具遇到这些请求时会返回 `unsolved` 或提示缺少支持，**不会编造结果**。

| 未覆盖内容 | 说明 / 替代做法 |
| --- | --- |
| 条件分布 `f_{X\|Y}`、条件期望 | 只支持条件概率（`P(A\|B)` 类数值计算）与联合/边缘分布的独立性判定 |
| 随机变量函数的分布（卷积公式、商的分布） | 未实现；可先用 `distribution_from_pmf` 手写分布律，或用 `numeric` 做蒙特卡洛式估计（非解析） |
| 二维正态分布 | 未实现；一维正态的 pdf/cdf/分位数、协方差与相关系数可用 |
| 协方差矩阵、随机向量 | 只支持两个变量的 `covariance` / `correlation`；多维协方差矩阵未实现 |
| 全期望公式、全方差公式 | 未实现；可拆成条件期望步骤手算，用工具做各步数值 |
| 大数定律、中心极限定理的**定理陈述与证明** | 只有中心极限定理的**近似计算**（`central_limit`）；证明类问题由模型讲解 |
| 顺序统计量（最大值/最小值的分布、极差分布） | 未实现 |
| χ²、F、t 分布的**分位数** | 无闭式反函数 → 工具如实返回 `unsolved` 并说明原因（正态分位数可用）；需要查表时请用数值求根（`numeric_solve` 对 cdf − α 求根）自行逼近 |
| 三变量及以上隐函数的**高阶**偏导 | 三变量隐函数只支持一阶；高阶会给出警告（`三变量隐函数的高阶偏导未实现，仅返回一阶`） |
| 重积分参数入口 | 引擎已注册 `integrate_multi` / `multiple_integral` / `iterated_integral`，但 **14 个工具的参数分派里没有暴露重积分入口**；可用嵌套定积分逐步计算或在一次调用中给出二次积分表达式 |
| 参数估计与假设检验的部分细节 | 已支持矩估计/极大似然、单正态总体均值与方差的置信区间、U/t/χ²/F/比例检验、样本均值与样本方差的抽样分布；**未支持**双总体比较的完整分支、非正态总体的精确检验、贝叶斯估计 |

## 3. 引擎与实现层面的限制

| 限制 | 现状 | 影响 / 替代做法 |
| --- | --- | --- |
| 未暴露为工具的 6 个算子 | `integrate_multi`、`numeric_matrix`、`moment_generating`(mgf)、`implicit_function_extremum`、`conditional_check`、`domain_check` 已注册在引擎里，但没有对应的工具参数入口 | 只能在 Python 层调用；对话中请用等价的工具组合 |
| 非线性相位振荡积分的数值精度 | 约 8 位有效数字（线性相位可达 20 位） | 高精度需求请用符号积分或分段处理 |
| `numeric_solve` 依赖初值 | 给定初值不同可能收敛到不同根 | 需要全部实根时请用符号 `solve` 或分区间多次调用 |
| `numeric_matrix` 精度 | float64 | 条件数 > 1e10 时给出警告；病态问题请用符号方法 |
| `mpmath` 路线退化 | 未装 `numpy`/`scipy` 时数值能力退化为 mpmath 单路线 | 需要更强数值能力时安装 scipy |
| 引擎在 `unsolved` 时的行为 | 返回失败原因并**记入失败账本**，相同参数不再自动重试 | 需要重试请改参数/换方法，或显式传 `retry: true` |
| 自动重建次数上限 | 引擎异常退出时最多自动重建 2 次（`MAX_AUTO_RESTARTS`） | 超过后需要用户干预（`math_status` 可查看状态） |

## 5. 调用方需要注意的工程约定

1. **参数名写错不会静默通过**：引擎按签名裁剪参数，被忽略的参数会在 `warnings` 里明确列出。
2. **`ARG_ALIASES` 是兜底而非正式用法**：引擎层做了大量别名（含中文方向词、`a→lower`/`b→upper` 等）以减少
   调用失败，但正式用法请按 [工具说明.md](工具说明.md) 里的参数名书写。注意 `a`/`b`/`n`/`k` 会被重映射
   （`n`/`k` → `order`），分布参数请用 `n`/`lam`/`mu`/`sigma` 等明确名字，或用 `params` 传 JSON 对象。
3. **`verification.status` 必须如实转述**：`numeric` 只代表数值抽样一致，**不构成解析证明**；
   `unverified` 表示未能验证。规格明确禁止把数值验证冒充严格证明。
4. **`unsolved` 不是错误**：它表示当前方法求不出解析解（例如 `∫x^x dx`），应把原因告知用户，
   不要用等价方法反复重试。
