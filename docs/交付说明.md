## 三、证据（关键实测记录）

- **端到端验收**：`cd E:\dsh-math; python -X utf8 _test_acceptance.py` → 通过 **111 例**、失败 0、跳过 0，**exit 0**，明细 `_test_acceptance_result.json`（`{"pass":111,"fail":0,"skip":0}`）。
- **八个专项测试**：`python -X utf8 _test_special.py` → `已注册算子 214 个；未加载模块：无`，八个专项逐个 PASS，末行「**八个专项：通过 8 / 8**」，**exit 0**。
- **引擎自检**：`engine/_selftest_{calculus,linalg,numeric,probability,probability_extra,symbolic_extra,verifier}.py` 全部 **exit 0**（numeric 为 `ok=17 PASS=17 FAIL=0`；verifier 45 例 `passed=True 23 / False 18 / None 4`；symbolic_extra 31 例无 error 无 traceback）。
- **宿主 loader 内真机验证**：`_verify/scratch_boot_full.mjs` 用宿主自身代码在隔离 profile 中启动 →
  `BOOT OK`，`ctx.tools.register` 收到 38 个工具（本插件 14 个全在），真机调用
  `math_simplify {"expr":"sin(x)^2+cos(x)^2"}`（1597 ms）→ `结果: 1`、`验证: 独立机制核验通过`；
  `math_integrate {"expr":"x^2","mode":"definite","lower":"0","upper":"1"}`（51 ms）→ `结果: 1/3 ≈ 0.3333333333333333`。
  输出见 `_verify/scratch_boot_full_out.txt`。
- **测试期间修复的真实缺陷（节选）**：关系运算符 `>=`/`<=`/`!=` 被静默解析成未定义函数（`ast.py` 的 `_RESERVED` 缺 `Ge/Le/Ne/Gt/Lt`）；`abs(x)` 被隐式乘法拆成 `a*b*s*x`；`is_unevaluated` 引用不存在的 `sp.Solve`；`result.approx` 第 13 位起错误；`numeric_agree` 多变量取同一点导致漏判；含参二次型 `.equals()` 挂死；`series_sum` 只返回 `Piecewise` 导致幂级数被判 unsolved；`y'(x)` 撇号解析失败；`implicit_diff` 变量角色歧义。逐条说明见 [测试报告.md](测试报告.md)。
